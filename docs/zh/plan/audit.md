**状态标记**

| 标记 | 含义 |
| --- | --- |
| **已完成** | 已达成，且可由仓库内容验证 |
| **部分** | 材料或实现已具备，但某项子条件未满足 |
| **未完成** | 尚未交付 |
| **修复中** | 已在本次审计会话中处理（见 §6） |
